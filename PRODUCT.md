# Colsdown

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Obsidian users evaluating responsive Markdown columns and stacks from the README or community plugin listing.

## Product Purpose

Keep note content editable as Markdown while presenting flexible side-by-side columns and vertical stacks.

## Operating Context

The current design task is a static release poster for the README and community listing, not a redesign of the plugin interface. Version1.1.0 is prepared in PR#7; no release publication or merge is authorized by this task.

## Capabilities and Constraints

The poster emphasizes four benefits: drag resizing, nested layouts, saved presets, and direct in-column editing. Keyboard navigation and layout reuse remain product capabilities but are not separate poster pitches. Live Preview editing keeps sibling columns rendered. Both compact comment markers and fenced layouts are supported. Existing runtime behavior is outside this design task.

## Brand Commitments

Preserve the established style and feel: cream ground, aubergine text, purple/lavender/lime geometric layout shapes, orange version accent, and bold Geist typography. Preserve the approved modular concept: the poster itself demonstrates the layout. Avoid the dark syntax label and tilted column blocks. The user allows copy and geometry refinements that make the four mechanisms clearer.

## Product Principles

- Keep the mechanism understandable at a glance.
- Express real capabilities without invented commercial claims.
- Keep the poster cohesive rather than accumulating caption rows.
- Preserve the existing plugin behavior and unrelated files.
