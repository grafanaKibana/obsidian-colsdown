# Colsdown

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Obsidian users evaluating responsive Markdown columns and stacks from the README or community plugin listing.

## Product Purpose

Keep note content editable as Markdown while presenting flexible side-by-side columns and vertical stacks.

## Operating Context

The current design task is a static release poster for the README and community listing, not a redesign of the plugin interface. Version1.1.0 is prepared in PR#7; no release publication or merge is authorized by this task.

## Capabilities and Constraints

Six benefits must remain represented: drag resizing, nested layouts, saved presets, direct in-column editing, keyboard navigation between columns and the note, and reusing layouts. Live Preview editing keeps sibling columns rendered. Both compact comment markers and fenced layouts are supported. Existing runtime behavior is outside this design task.

## Brand Commitments

Preserve the established style and feel: cream ground, aubergine text, purple/lavender/lime geometric layout shapes, orange version accent, and bold Geist typography. Reimagine the composition fully. Avoid the dark syntax label and tilted column blocks. The user explicitly allows rewriting the six feature phrases while preserving their benefits.

## Product Principles

- Keep the mechanism understandable at a glance.
- Express real capabilities without invented commercial claims.
- Keep the poster cohesive rather than accumulating caption rows.
- Preserve the existing plugin behavior and unrelated files.
